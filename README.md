# Gallop Streetwear Website 👕✨

A modern and responsive fashion website built for **Gallop**, a proudly South African streetwear brand.

This project was created as part of the **Future Interns Full Stack Web Development Task 3 (2026)** initiative, which focuses on building real-world solutions for local businesses.

---

## 🌍 About Gallop

Gallop is a Black-owned South African streetwear brand focused on delivering stylish, affordable, and inclusive fashion.

The brand was created from a passion for original fashion and a desire to move away from counterfeit clothing culture. What started as a simple sketch of a galloping horse in a rural community evolved into a growing local fashion brand built on:
- quality
- identity
- individuality
- community pride

Gallop currently offers:
- T-Shirts
- Sweaters
- Tee & Short Sets
- Upcoming Perfume Collection

The goal of this project was to build a professional online presence for a real local business and help improve:

## 🛒 WhatsApp Ordering System

Instead of using a full e-commerce backend, this website uses a lightweight WhatsApp ordering flow.

Customers can:
1. Select a product size
2. Click “Add to Cart”
3. Automatically send a pre-filled WhatsApp order message to the business owner

This solution was chosen because the business already operates actively through WhatsApp.

## 🎤 Project Pitch

Gallop is a proudly South African streetwear brand focused on delivering stylish, affordable, and inclusive fashion. The brand started from a passion for original fashion and has grown into a developing local business with a strong identity and vision.

I created this website to help Gallop build a stronger online presence and present the brand more professionally to customers. Before the website, the business mainly relied on social media and WhatsApp communication, which made it difficult for customers to browse products easily in one place.

The website helps solve this by giving customers a clean and modern platform where they can explore products, learn about the brand, view collections, and place orders directly through WhatsApp. The responsive design also makes the website accessible on both mobile and desktop devices.

This project demonstrates how modern websites can help local businesses improve customer trust, increase visibility, and create a smoother online shopping experience.
